1. المخطط العام لمعمارية لوحة التحكم (Architecture Overview)

يوضح هذا المخطط تسلسل تسجيل دخول المشرف وفحص صلاحيات المدير (Role: Admin)، ثم التفرع لكافة أقسام إدارة النظام:

graph TD
    Admin([مدير النظام / Admin]) --> Auth{تسجيل الدخول /login}
    Auth -->|بيانات خاطئة| AuthFail[رسالة خطأ وإعادة المحاولة]
    Auth -->|بيانات صحيحة| CheckRole{فحص الصلاحية Role == admin}
    CheckRole -->|مستخدم عادي| UserDash[لوحة العميل /home]

2. دورة حياة الحجز الطبي (Appointment Lifecycle Flow)

تدرج الحجز الطبي عبر الحالات المختلفة منذ تسجيل المريض له وحتى إتمام الكشف في العيادة:

stateDiagram-v2
    [*] --> Pending: حجز جديد من المريض (قيد الانتظار)
    Pending --> Confirmed: تأكيد الموعد والتواصل من الإدارة
    Pending --> Cancelled: اعتذار أو رفض الحجز
    Confirmed --> Completed: حضور المريض وإتمام الكشف الطبي
    Confirmed --> Cancelled: إلغاء الموعد لظرف طارئ
    Completed --> [*]
    Cancelled --> [*]

تسلسل إشعارات وتأكيد الحجز:

sequenceDiagram
    autonumber
    actor Patient as المريض / الزائر
    participant System as نظام صيدليتي
    actor Admin as مدير النظام
    participant Doctor as الطبيب المعالج

    Patient->>System: تعبئة نموذج حجز موعد (طبيب، تاريخ، وقت، هاتف)
    System->>System: التحقق من عدم وجود تعارض زمني
    System->>Admin: إرسال إشعار فوري بحجز جديد (Notification)
    System-->>Patient: إرسال بريد إلكتروني بتفاصيل الحجز المبدئي
    Admin->>System: فتح لوحة الحجوزات وتغيير الحالة إلى (مؤكد Confirmed)
    System-->>Patient: تأكيد الموعد والتواصل الهاتفي
    Admin->>System: بعد الموعد تغيير الحالة إلى (مكتمل Completed)

3. مخطط معالجة طلبات الأدوية (Order Processing Flowchart)

خطوات مراجعة الطلب الجديد، فحص المخزون، وتوجيهه للتوصيل أو الاستلام من الفرع:

flowchart TD
    NewOrder([وصول طلب شراء جديد]) --> ViewOrder[عرض تفاصيل الطلب والأدوية المطلوبة]
    ViewOrder --> CheckStock{التحقق من توافر الكميات بالمخزن}
    
    CheckStock -->|غير متوفر| CancelOrder[تغيير الحالة إلى ملغي Cancelled]
    CancelOrder --> ContactCustCancel[التواصل مع العميل وإبلاغه]
    
    CheckStock -->|متوفر| ProcessOrder[تغيير الحالة إلى قيد التجهيز Processing]
    ProcessOrder --> PickPack[تجهيز الأدوية من الرفوف وتغليفها]
    
    PickPack --> DeliveryType{نوع الاستلام؟}
    DeliveryType -->|توصيل للمنزل Delivery| DispatchCourier[تسليم الطلب لمندوب التوصيل]
    DeliveryType -->|استلام من الصيدلية Pickup| ReadyAtBranch[الطلب جاهز بالفرع للاستلام]
    
    DispatchCourier --> CompleteOrder[تغيير الحالة إلى مكتمل Completed]
    ReadyAtBranch --> CompleteOrder
    CompleteOrder --> ExportExcel[إمكانية تصدير البيانات إلى Excel بنقرة واحدة]

4. وحدات الإدارة الشاملة (CRUD Operations)

إدارة الأطباء (/doctor)

إضافة أطباء جدد مع تحديد التخصص، وسعر الكشف، والهاتف، والمحافظة، وصور العيادة، مع إمكانية تعديل البيانات أو الحذف.

إدارة الأدوية (/medicien)

إدارة مخزون الصيدلية، تحديد نوع الدواء (أقراص/شراب/فوار)، والأسعار، ودواعي الاستعمال، والكميات المتوفرة وتنبيهات النواقص.

إدارة المستخدمين (/users)

الاطلاع على جميع المسجلين، تعيين الأدوار والصلاحيات (مدير / عميل)، وتعديل الحسابات وتأكيد العناوين.

تصدير البيانات (Excel Export)

استخراج تقارير المبيعات وجداول الطلبات بتنسيق Excel فوري بضغطة زر لمتابعة الحسابات والأرباح.

6. جدول خريطة مسارات لوحة التحكم (Admin Sitemap)

الصفحة المسار (Route) الوظيفة والتحكم الصلاحية
الرئيسية /admin/dashboard الإحصائيات العامة وأحدث العمليات والتنبيهات مدير النظام
الحجوزات /admin/appointments استعراض الحجوزات وتغيير الحالات (مؤكد/ملغي) مدير النظام
الطلبات /admin/orders إدارة طلبيات الأدوية وتتبع الشحن والتجهيز مدير النظام
تصدير الطلبات /admin/orders-export تنزيل ملف Excel يحتوي على بيانات الطلبات والمبيعات تحميل ملف
التقارير /admin/reports رسوم بيانية وإيرادات المبيعات ونشاط الزوار مدير النظام
الأطباء /doctor إضافة وتعديل وحذف بيانات الأطباء والعيادات مدير النظام
الأدوية /medicien إضافة أصناف الأدوية وتحديث الأسعار والكميات مدير النظام
